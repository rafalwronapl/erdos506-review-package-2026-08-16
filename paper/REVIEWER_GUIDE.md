# Reviewer guide

This manuscript treats the convention in which the finite planar point set is
neither collinear nor concyclic and proper Euclidean circles containing a
non-collinear selected triple are counted once.  It does not claim the
stronger general-position variant forbidding every collinear triple.

The proof is intended to be read in three layers:

1. the conceptual block/inversion apparatus and the cases \(n=4,\ldots,9\);
2. a finite boundary window \(n=10,\ldots,13\), with each case reduced to
   named geometric lemmas;
3. a direct two-case proof at \(n=14\) and one uniform capped-block
   functional for every \(n\ge15\).

There is no deletion, induction, or sixteen-point base case in the canonical
proof.  Fixed rational multipliers are displayed certificates of stated
inequalities, not the output of a configuration search.  The appendix must
expose enough of each certificate for coefficientwise hand checking.
Independent scripts are secondary arithmetic checks only; the written proof
must make every case division and every geometric implication visible.

During drafting, `% REVIEW GAP:` is a hard failure marker.  A section carrying
such a marker must not be represented as a complete proof.
